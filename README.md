# RUNYA Fitness App

RUNYA is a minimal fitness app prototype. The project includes:

- **frontend**: React-based web interface styled to mimic an iPhone screen.
- **backend**: Node.js + Express API with MongoDB models.
- **database**: schema description.
- **ios**: stub instructions for a React Native port.
- **deploy**: WordPress embed snippet and hosting notes.

This repository contains skeletal code to get started with further development.
