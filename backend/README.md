# RUNYA Backend

Node.js and Express API server for the RUNYA fitness app. Uses MongoDB via Mongoose.

## Endpoints
- `POST /api/register`
- `POST /api/login`
- `GET /api/user`
- `GET/POST /api/workouts`
- `GET/POST /api/meals`
- `GET /api/progress`
- `GET /api/export`

Run with `npm start`. Ensure MongoDB is running and `MONGO_URL` environment variable is set if not using the default.
