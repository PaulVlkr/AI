# RUNYA iOS App

This folder contains a basic React Native setup for future native iOS support. It reuses the same REST API as the web app.

Steps to start a new React Native project:

```bash
npx react-native init RunyaMobile
cd RunyaMobile
# implement screens similar to the web app
```

The mobile app should support swipe gestures, pull to refresh, and optionally integrate with Apple HealthKit.
